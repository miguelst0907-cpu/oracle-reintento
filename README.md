# Reintento del servidor gratuito de Oracle

Intenta crear cada hora el servidor Always Free de Oracle (1 OCPU / 6 GB ARM) hasta que haya hueco,
avisa por Telegram con la IP y se desactiva solo. Las claves están en el secreto cifrado `ORACLE_BUNDLE`
(nunca en el código). Temporal: se borrará cuando el servidor esté creado.
